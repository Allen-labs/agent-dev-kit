# Test

跑测试并确保全绿。失败则分析根因、修复、重跑。

## 步骤

1. **检测框架**：从 package.json / pyproject.toml / go.mod 等识别（Jest / Vitest / pytest / cargo test 等）
2. **运行**：执行对应的测试命令（$ARGUMENTS 可指定模式或单个测试）
3. **失败分析**：逐个失败项找根因——是断言过时、逻辑改动、还是测试本身写错？**修根因，不修症状**（不要为了过测试而删断言）
4. **重跑**：修复后重跑，直到全绿
5. **确认**：全绿才算完，报告覆盖结果（跑了几条、修了几条、改了哪些文件）

## 纪律

- 新增/修改逻辑必须同步补测试，即使没人要求
- 别用 `it.only` / `skip` 掩盖失败
- 别 mock 掉真实行为来骗过测试
